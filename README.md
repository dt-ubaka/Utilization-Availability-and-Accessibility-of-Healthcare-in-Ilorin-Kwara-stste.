# Utilization-Availability-and-Accessibility-of-Healthcare-in-Ilorin-Kwara-stste.
Study on the impact of Nigeria’s NHIS on healthcare utilization in Ilorin. Surveyed 400 respondents; 73% enrolled. Income, occupation &amp; education shaped usage. Strong correlation found between NHIS and healthcare access. Recommends better infrastructure, training &amp; anti‑corruption measures.
